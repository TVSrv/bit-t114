# Участие в разработке «Бита»

Спасибо за интерес к проекту! Обсуждения, отчёты об ошибках и PR приветствуются после открытия репозитория.

## Как сообщить об ошибке

Укажите:
1. Версию прошивки T114 и версию Android.
2. Модель устройства и Android (если проблема в приложении).
3. Шаги воспроизведения, ожидаемый и фактический результат.
4. Скриншот без персональных данных, если проблема визуальная.
5. Лог без токенов, MAC-адресов, кодов восстановления и других секретов.

## Перед Pull Request

- Создайте отдельную ветку от актуальной рабочей ветки.
- Запустите тесты:
  ```bash
  g++ -O2 -std=c++17 -o /tmp/bit-ft sim/features_test.cpp core/*.cpp && /tmp/bit-ft
  g++ -O2 -std=c++17 -o /tmp/bit-gps sim/gps_test.cpp core/gps.cpp && /tmp/bit-gps
  ```
- Для изменения Android проверьте `cd android && ./gradlew assembleDebug`.
- Для изменения T114 проверьте `pio run -e t114`.
- Для изменений графики приложите реальные кадры симулятора и проверьте все формы/комнаты, сон, температуру и выдвижное меню.

Передавая изменения кода через Pull Request, убедитесь, что имеете право предоставить их на условиях MIT. **Для графики** действуют отдельные ограничения: [ASSETS-LICENSE.md](ASSETS-LICENSE.md); не добавляйте изображения, если у вас нет прав на их публикацию.
