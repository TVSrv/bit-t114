# Безопасность / Security

## Сообщить об уязвимости

Пока проект готовится к публичной публикации, **не размещайте** в открытых Issues сведения, позволяющие воспроизвести эксплуатацию, токены, ключи, коды восстановления питомца или приватные данные. Используйте приватное сообщение владельцу репозитория через GitHub либо GitHub Private Vulnerability Reporting, если функция включена.

Не публикуйте конфиденциальные логи Bluetooth, полные коды резервного восстановления или данные телефона.

## Поддерживаемые версии

| Версия | Статус |
|---|---|
| Firmware 0.41 / Android 0.19 | Экспериментальная; исправления по мере проверки |
| Более ранние версии | Для отката, без гарантии исправлений безопасности |

**Ограничения:** BLE-подключение и команды должны использоваться только на доверенном устройстве; резервные коды храните приватно. Debug APK из CI не является релизом с постоянной подписью.
