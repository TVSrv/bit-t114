# Реальные скриншоты «Бита» / Screenshot provenance

## Подтверждённые кадры прошивки 0.41

В каталоге [`docs/screenshots/`](screenshots/) находятся **восемь кадров, полученных из настоящего кода `0.41-sync-test`**, а не нарисованные иллюстрации:

| Файл | Что показано |
|---|---|
| `01-home-fullscreen.png` | Комната Джуна на всю высоту, меню скрыто |
| `02-menu-sliding.png` | Меню выдвигается снизу, промежуточный кадр (120 мс) |
| `03-menu-open.png` | Выдвижное меню открыто, выбран первый значок |
| `04-menu-selection.png` | Выбран пункт «Уборка» |
| `05-middle-evening.png` | Мидл, вечернее освещение |
| `06-hacker-day.png` | Хакер в своей комнате |
| `07-junior-sleep.png` | Джун спит ночью |
| `08-senior-bugs.png` | Сеньор и два бага на полу |

**Точная технология создания:** [`sim/docs_shots.cpp`](../sim/docs_shots.cpp) запускает `Game::render(gfx::Canvas)` из ядра прошивки 0.41, записывает каждый кадр как PPM 240×135. [GitHub Actions](https://github.com/TVSrv/bit-t114/actions/workflows/real-screenshots.yml) преобразует PPM в PNG **без изменения интерфейса**, увеличив изображение до 720×405 методом nearest-neighbor. Нет перерисованных элементов или наложенных мокапов. Снимки сделаны на симуляторе, а не фотографиями реальной платы.

В данном исходном снимке находится **0.41-sync-test**. Все кадры получены из этого же графического ядра.

### Как воспроизвести на ветке 0.41

```bash
git checkout main
mkdir -p build/actual-shots
g++ -O2 -std=c++17 -o /tmp/bit-docs-shots sim/docs_shots.cpp core/*.cpp
/tmp/bit-docs-shots build/actual-shots
```

Полученные PPM имеют исходное разрешение дисплея **240×135**. В [workflow](../.github/workflows/real-screenshots.yml) указан конвертер в PNG.

## Android 0.19

**Актуальные кадры Android 0.19 отсутствуют.** Нельзя использовать старые концепты как будто это реальный интерфейс новой версии. Снимки следует получить из установленного APK на телефоне или Android-эмуляторе, затем проверить, что видны три вкладки «Питомец», «Развитие», «Устройство» и зеркало питомца, соответствующее подключённой T114.

## Дизайн-материалы и старые изображения

В старом приватном проекте были дизайнерские материалы `bit-art/` и устаревшие листы `previews/`. Они **не включены в чистый публичный архив**, пока не подтверждены права на их распространение. В публичной галерее используются только восемь кадров, полученных непосредственно из версии 0.41.
